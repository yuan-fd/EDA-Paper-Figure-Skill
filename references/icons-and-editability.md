# 图标来源与 PPT 可编辑交付

## 1. 来源与选取

论文图标从 [Flaticon](https://www.flaticon.com/) 检索，使用适量、含义明确的素材，不自行设计或通过生成图像创造图标。模块矩形、圆柱、箭头和电路逻辑符号是图的语义图形，继续按研究内容绘制。

先明确图标要标识的对象，再检索，例如 agent / robot、analysis、chip、database、workflow、code、execution。优先同一作者或同一套 outline / line 风格，统一视觉重量、笔画、配色和与标题的对齐。可从 [Robotics — Basic Outline](https://www.flaticon.com/packs/robotics-59) 等实际图标集合浏览，再按当前图的对象选择。

图标主要帮助识别角色、工具、支持资源或关键概念。数量随内容决定，不设全图固定配额，不给所有步骤补一枚图标。图标不能压过标题或让文字缩小；同类身份可重复使用同一图标，不为每个实例制造新的视觉类别。

获取所选图标的矢量版本，保存条目链接、作者、素材名称/ID 和对应许可/署名信息。按现有授权下载并保留原始来源；需要署名时在适当位置保留署名。分享 skill 时优先提供来源链接，按具体许可处理原始图标文件的再分发。

## 2. PPT 中的编辑能力

交付时，图标应由 PowerPoint 原生形状或自定义矢量路径组成，可整体移动/缩放，可改填充与线条，部件可独立选择，路径可在适用时编辑节点。

一枚 PNG 是图片；一枚插入的 SVG 也可能仍是单个图片对象。它们不能满足本项目对图标原生编辑的要求。需要完成形状/路径转换后再保存最终 PPTX，不能让用户在收到文件后才自行转换。

常用做法：

1. 从 Flaticon 获取所选矢量素材，保留原图标结构。
2. 在当前可用的 PowerPoint 中使用 SVG 的 Convert to Shape 功能，或通过现有工具把矢量路径转换为 PPT 原生自定义形状。
3. 保留必要的子路径、孔洞、变换、填充和线条，使转换结果与原图一致；不以手工近似拼画替代。
4. 将转换后的部件按每枚图标编组，并赋予清楚名称，便于移动、选择和取消组合。
5. 重开或重新导入最终 PPTX，核对对象结构、部件编辑和最终外观。

Office 的具体支持和操作见 [Microsoft：Edit SVG images in Microsoft 365](https://support.microsoft.com/en-gb/office/graphics-visuals/edit-svg-images-in-microsoft-365)。使用当前实际工具与版本完成转换；不预设所有应用都提供同一按钮。

## 3. 验收

原生对象检查针对图标本身：PPTX 中应能定位到相应的形状/路径对象（如 `p:sp`，需要组合时可包含在 `p:grpSp` 内）。不得仅以 `p:pic` 包裹的 PNG / SVG 或图片填充形状交付。

同时检查实际编辑行为和渲染：

- 图标与原始矢量素材一致，没有丢部件、孔洞或错位。
- 图标编组可独立操作，形状部件或路径保留编辑能力。
- 图标缩放到最终印刷尺寸仍可辨，笔画与其它图标一致。
- 按实际完成的方式报告核验；软件重新导入与在 PowerPoint 中亲自操作要准确区分。

原理图、版图截图、实验照片可以按其本来性质作为图片；图标验收不要求删除这些正常研究图像。

## 4. 历史样例的使用

已确认样例保留当时实际的素材与制作方式。继续制作或替换图标时执行本文件的 Flaticon 选取与原生编辑规则；展示图的原始像素、颜色和布局按用户提供文件保存。
