# 已确认样例：Agent 系统架构图

这是用户在多轮修改后明确确认“这次图像终于可以了”的版本。它作为视觉和几何基线，不能代替下一幅图的论文内容。

以下坐标、配色与删除项仅针对该张总体架构。后续单栏方法图、比较图不继承其固定构图；跨图字体与排版以 [构图、文字与系列风格](composition-and-typography.md) 的当前约定为准。其它案例状态见 [后续案例](case-studies.md)。

## 直接可用的资源

- [最终外观 PNG](../assets/accepted-architecture.png)：查看视觉层级、字号比例、回路通道和留白。
- [原生 Draw.io](../assets/accepted-architecture.drawio)：逐对象编辑的范围框、文字、椭圆和边。
- [原生 PPTX](../assets/accepted-architecture.pptx)：单页可编辑形状、文字和自由路径。

需要照着上一幅继续改时可复制原生文件另存；新图职责不同则只借鉴语法，不复用不存在的角色或关系。

历史原生文件保留实际制作方式。新图标按 [Flaticon 来源与原生编辑规则](icons-and-editability.md) 选取并转换；当前成果展示使用用户选定的四张图，见 [README](../README.md)。

## 最终布局的关键约束

| 属性 | 已确认状态 |
| --- | --- |
| 外部输入 | Context and Prompt 及单独的 Illustrative prompt |
| 分层 | Coordination、Specialized workflows、Shared infrastructure |
| 支持 Agent | Design Analysis Agent，在优化动作紫色范围之外 |
| 动作 Agent | Flow Optimization、Algorithm Evolution、Timing ECO |
| Agent 表达 | 白框、红色名字、小红机器人、浅蓝步骤框 |
| 底座 | 两个圆柱；无图标；无标题白框；蓝色标题；能力仍在白框 |
| 方法标签 | 删除 A2-ORFO、DPLEvolve / GoalEvolve 和 Post-route |
| 路径标签 | 无框纯文字 |
| 分隔符 | 无中间圆点，使用逗号或斜杠 |
| 内部回路 | Review 左出，在更靠左的通道上行，再向右进入 Assess 左侧 |
| Control 等距 | 五个等高框，四条竖箭头等长 |
| 分发对齐 | 第四个 Control 步骤中心与中间优化分支对齐 |
| 分发对称 | 上、中、下分支等距；主干位于源/目标通道中点 |
| 底部反馈 | 靠背景板下沿，保持可见间隙；无多余页脚和图例 |

## 已实际核验的边界

- 单页 PPTX：188 个原生形状/路径对象，77 个文本对象，26 个箭头头部；没有用整幅图片代替图。
- PPTX 从最终包重新导入并渲染，核对了流程间距、分发总线、内部回路、底座标题和底部反馈。
- 论文图预览宽约 183 mm；最终 PDF 最小字体 5.3 pt。
- PDF 碰撞检查没有 FAIL；五个关系标签跨浅背景边界的 WARN 经人工核对可接受。
- PPTX 结构检查中的外围多折线包围盒提示，经真实路径核对没有穿过文字。自动检查只提供证据，外观仍要目视。

## 不要复活的中途方案

深底白字 Agent 名、步骤旁的 Task/Checkpoint 图标、两个 Review/Revise 标签、专业 Agent 下方的产物图标、底座小图标、橙色底座标题、方法名小框、带框路径标签、Post-route 标签、底部图例与反馈说明句，都曾被替换或明确删除。

这些删除项不是“待补齐内容”。后续用户没有重新要求，就保持删除。
